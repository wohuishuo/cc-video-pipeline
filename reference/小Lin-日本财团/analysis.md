# 拍摄 SOP：宏观+微观+收束型知识科普（地理/经济/制度类）
> 拆解自：小Lin说《日本财团，背后有什么玄机？》
> 数据：14分 / 141句 / 375个镜头切换（平均2.24秒/镜） / 居家精致机位 / 349万播放·5.1k弹幕

## 一句话结构
**用"普通人熟悉的品牌（罗森/无印良品/丰田）"做钩子 → 揭秘这都是 6 大财团（"日本经济特区"）→ 三层结构（**银行爸爸 + 商社妈妈 + 实业儿女**）→ 商社的情报 + 投资 + 贸易三秘密 → 90 年代泡沫破裂 + 三股拆家力量 → 巴菲特 2020 飞来劝分红 + 财团今生**。
本质是"**用大白话讲一个大多数人听过但讲不清的日本经济现象**"。

## 钩子拆解
- **共鸣型钩子**（0:00-0:06）："哎，我们都知道财团在日本的势力非常大" — "我们都知道"假装观众已经知道，制造"原来我不知道"的悬念
- **八卦型钩子**（3:33-3:55）：丰田家族三代家谱 + 联姻三井 — "日本财团是一家人"用具体家谱让"利益绑定"从抽象变可见
- **猎奇型钩子**（7:30-7:45）："不保真的都市传说"——1973年三菱商社通过王进喜照片推算大庆油田位置然后中标

## ✅ 你可以直接照搬的 SOP

### 公式 1：共鸣型钩子
```
"我们都知道/都听过/都用过 [现象A]..."
→ 30秒内抛出 3-5 个熟悉的例子
→ "你不知道的是，它们全是 [统一身份] 的人"
```

### 公式 2：家庭关系科普
```
"老板 + 老板娘 + 员工" 三层比喻
"爸爸管钱（银行）、妈妈管方向（商社）、孩子干活（实业）"
```

### 公式 3：八卦型钩子
```
"不保真的都市传说" + 具体家谱/具体人名/具体数字
"曾祖的舅舅→祖父的堂兄→本人的姐姐"
```

### 公式 4：质疑+反转
```
"你以为 [常规认知]...  错。"
"它真正在做的是 [更深层的事情]"
"举个 🌰 [具体案例]"
```

### 公式 5：宏观+微观+收束
```
[国家名] 过去/现在/未来  时间轴
"早期 A → 后来 B → 现在 C → 未来 D"
→ 最后一句接下期预告（钩子留存）
```

### 节奏配方（适合 8-15 分钟科普向）
- 钩子：0-30s 内抛 3-5 个熟悉例子
- 段落切镜密度：1.6-2.5s/镜（高于书单视频的 5.2s/镜）
- 段落长度：每段 1-3 分钟，段落之间用"好，说完了 A，现在说 B"
- 每段必须有：1 个比喻 + 1 个具体案例 + 1 个数字
- 收尾：升华 + 下期预告（钩子留存）
