# 网文小说 视频稿模板（金字塔 × 小Lin SOP）

> 适用：单本网文的推书/读后感/安利，3–6 分钟口播，B站横屏 + 抖音/TikTok 竖屏
> 内核：**结论先行**（金字塔）+ **讲一个具体场面而非复述大纲**（小Lin SOP）+ **私人故事建可信度**
> 用法：把每个【】里的内容替换成你的，删掉提示。一行口播≈每秒 4 字，按时长砍内容。

---

## 黄金结构（7 段，照抄顺序）

```
钩子(0–8s) → 一句话结论 → 设定钩子(金手指/脑洞) → 一个名场面(讲透不剧透)
→ 人物或情感爆点 → 适合谁+避雷 → 互动收尾
```

---

## 填空骨架

**① 钩子（0–8 秒，必须最先抛）**
> 【从下面"钩子库"选一种，一句话，不交代书名】
例：「我熬夜两个通宵，就为了看一个废柴怎么把全世界都骗过去。」

**② 一句话结论（金字塔顶，先给答案）**
> 这本【书名】，一句话：【它最大的爽点/独特价值，一句说完】。
例：「《诡秘之主》一句话——把克苏鲁恐怖写成了升级爽文，还让你边怕边爽。」

**③ 设定钩子（这本书凭什么不一样）**
> 它的核心设定是【金手指/世界观/脑洞】，跟同类不一样的地方是【差异点】。
> （只讲设定，别展开剧情。20–30 秒）

**④ 一个名场面（★最关键★，讲透一个点，不复述大纲）**
> 我印象最深的一段是【某个具体场景/反转/名台词】，
> 当时【发生了什么，为什么炸】。
> （小Lin 法则：挑**一个**点讲到让人起鸡皮疙瘩，绝不"然后然后"地复述目录。40–60 秒）

**⑤ 人物 / 情感爆点 + 私人故事（建立"我真看过"）**
> 【某个角色】最打动我，因为【他的选择/弧光】。
> 我自己【读到这里时的真实反应/联想到的事】← 私人故事是你对抗"AI 水文推书"的护城河。

**⑥ 适合谁 + 避雷（给观众决策）**
> 适合【什么口味的人】看；如果你【不能接受X/雷点】，那可能不适合你。
> （诚实避雷反而更可信，小Lin 也踩同行"凑数书单"来立信）

**⑦ 互动收尾（算法友好）**
> 【固定品牌口号 / 一句钩子】。你看过的话，评论区告诉我【一个具体问题】，
> 也安利一本你心里的神作，我们做个"信息置换"。

## 钩子库（① 处选一种）

| 类型 | 模板 | 例 |
|---|---|---|
| 痛点 | 「找不到好看的网文？这本…」 | 「书荒的人看过来」 |
| 反常识 | 「都说X，但这本偏偏…」 | 「谁说穿越文都套路」 |
| 悬念 | 「一个【身份】，做了一件【反常的事】」 | 「一个反派，救了主角全家」 |
| 数据/权威 | 「连追三年、X万收藏的…」 | 「起点封神榜常客」 |
| 情绪 | 「看完那晚我没睡着」 | 「结局让我哭了」 |
| 身份标签 | 「【你的人设】私藏书单第N本」 | （配合账号定位） |

## ★画面配置（小Lin式高级感的真正来源）★
> 实测小Lin视频：高级感不在音效（BGM只56%低床垫、几乎无音效），全在**每个观点都叠一层视觉支撑**。
> 光口播=普通读后感；配齐下面这层=高级感。写稿时**每段右边先标好配什么画面**。

| 稿子段落 | 配的画面（照这个准备素材） |
|---|---|
| ① 钩子 | 设计动画开场 / 名场面影视化片段 / 大字标题卡 |
| ② 结论 | 黑底大字"书名"标题卡（=章节感） |
| ③ 设定钩子 | 世界观示意图 / 关键设定的动画文字清单（逐条弹） |
| ④ 名场面 | 该场景的影视化片段 / 同人图 / 自制分镜图 |
| ⑤ 人物+私人 | 角色立绘/卡 + 你出镜口播（A-roll 回切） |
| ⑥ 适合谁+避雷 | 动画文字清单（适合✅/避雷⚠️ 两栏弹出） |
| ⑦ 收尾 | 固定品牌卡 + 评论区引导动画 |

**最省力的视觉层（无影视化素材时）**：书封面满屏 + 动画文字清单 + 你出镜，三样交替也能撑起信息密度。

## 节奏 / 双版本

- **时长**：3 分钟≈720 字；6 分钟≈1440 字。先写满再砍到目标。
- **横屏(B站)**：可多给设定/背景信息（观众耐受高）。
- **竖屏(抖音/TikTok)**：钩子压到前 3 秒，砍掉铺垫，名场面提前。
- **出海(中俄英日)**：钩子和书名按目标语种习惯改写，不直译；保留人名/术语准确。

## 一个填好的示例（《诡秘之主》3 分钟版）

> **钩子**：「我从来没想过，克苏鲁的恐怖，能让我边吓得头皮发麻边喊'好爽'。」
> **结论**：一句话——《诡秘之主》把不可名状的恐怖，写成了一部能升级的爽文。
> **设定钩子**：它的金手指是"塔罗会"和序列体系，你靠扮演不同的"途径"一步步变强，但每升一级就离发疯更近一步——力量和代价是绑死的。
> **名场面**：最炸的是主角第一次"扮演"成功的瞬间——他明明在骗整个世界，却因为'信仰'真的获得了力量。那种"假戏成真"的设定，我当时直接坐起来了。
> **情感+私人**：克莱恩这个角色最戳我，他越强越孤独。我自己加班到凌晨追更，就为了看他怎么在理智和力量之间走钢丝。
> **适合谁+避雷**：适合喜欢严谨世界观、烧脑设定的人；如果你只想要无脑爽，前期节奏可能偏慢，慎入。
> **收尾**：精读经典，也读好网文。评论区告诉我你追的第一本网文是哪本，我下期讲讲它。
