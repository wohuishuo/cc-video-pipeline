# Creator Profile Discovery implementation plan

1. Define URL, item, page and manifest contracts with canonical serialization.
2. Prove serial page checkpoints, deduplication, replay, conflict and failure resume with a fake enumerator.
3. Implement yt-dlp and pinned-F2 adapters behind the same page protocol.
4. Expose a portable PowerShell launcher, installer, MVP manifest and documentation.
5. Run a bounded real Douyin profile enumeration with optional cookies and record honest evidence.
6. Connect the committed Creator Manifest to Graph Studio without moving discovery state into the control plane.
