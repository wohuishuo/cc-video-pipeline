# Publication vertical slice brief

Observable result: a verified video, editable metadata and target/account selections become an immutable Publication Plan; a separate exact-hash confirmation executes targets serially and checkpoints receipts.

Publication owns intent, visibility policy, confirmation and continuation. Platform I/O owns sessions and upload commands. The video and metadata remain owned by their producers. Graph Studio creates plans only.

Default plans are private/draft. Execution refuses platforms whose pinned adapter cannot guarantee that visibility. Public intent requires an explicit CLI flag and still requires the plan hash.
