# Video Graph Studio Vertical Slice

**Observable result:** A creator creates, queues, observes, cancels and recovers durable folder/URL video Graphs from a local browser, then previews hash-verified results and sees their output location, elapsed time, size and reported cloud-token usage before any optional publication action.

The Graph Definition, Workflow Run, Workflow Process, Local Worker and Run Log have separate state ownership. Stable operation IDs, canonical fingerprints, optimistic versions, checkpoints, process cleanup, loopback binding and allowed-root path checks are protected invariants.

Unbounded parallel processing, unverified real-platform publishing, cloud identity, distributed resources and billing are non-goals for this slice. Platform account and visibility controls must expose capability truth and cannot turn plan-only adapters into claimed upload support. The detailed project artifact is in [`docs/project/evidence/video-graph-studio/vertical-slice-brief.md`](../../project/evidence/video-graph-studio/vertical-slice-brief.md).
