# 信息差生意 30 分钟长视频 SOP

主题：利用信息差、认知差和焦虑赚钱的生意。

目标不是把两个素材逐段复述，而是压成一条观众能听懂、记住、拿走使用的主线：

> 信息差生意最危险的地方，不是它贵，而是卖方早就知道真实成本、成功率、退出机制和失败风险；买方却只看到成功案例、身份想象和限时名额。

## 核心表达规则

每一段都按三层金字塔写：

```text
结论
→ 根据
→ 例子
```

写完后做逻辑链检查：

- 结论是否能在一分钟内讲清楚。
- 根据是否真的支撑结论。
- 例子是否具体，而不是重复观点。
- 是否站在观众位置上，帮他判断，而不是炫耀分类。
- 图是辅助，不能替代口播。
- 走最短路径，直接给观众结论和判断方法，不复述创作者的推理弯路。

## 两个附件的用法

第一个附件用于“丰富度”：

- 行业分类。
- 心理操控点。
- 话术结构。
- 隐形利益链。
- 高密度案例池。

第二个附件用于“可信度和工具感”：

- 四层边界：正常生意、割韭菜、违法营销、刑事诈骗。
- 共同结构：免费筛选、卖未来身份、幸存者偏差、多层收费、风险转移。
- 公开案例和监管线索。
- 最后的五个识别问题。

正式成片时，优先保留第二个附件的判断框架，再从第一个附件挑行业例子填充。

## 30 分钟结构

按中文口播约 230-260 字/分钟估算，30 分钟稿件约 7000-7800 字。

| 时间 | 章节 | 任务 |
|---:|---|---|
| 0:00-1:00 | 开场钩子 | 用一个普通人会遇到的场景切入：9.9 体验课、免费体检、低价加盟、AI 副业课。 |
| 1:00-2:30 | 一句话结论 | 明确告诉观众：这期不是骂所有高毛利生意，而是教你识别“卖方失败也赚钱”的结构。 |
| 2:30-5:30 | 边界声明 | 四层分类：正常生意、割韭菜、违法营销、刑事诈骗。避免把所有课程/加盟一棍子打死。 |
| 5:30-9:00 | 第一把刀：筛选器 | 免费直播、9.9 课、免费鸡蛋、免费检测的本质是筛选最可能付款的人。 |
| 9:00-13:00 | 第二把刀：卖身份 | 不卖产品，卖“未来的你”：自由职业者、独立女性、城市合伙人、传承人、AI 红利玩家。 |
| 13:00-17:30 | 第三把刀：成功案例替代概率 | 只展示月入三万、一个月回本，不公开总人数、中位数、失败率和净利润。 |
| 17:30-22:00 | 第四把刀：利润藏在第二层 | 高阶课、陪跑、设备、原料、API、广告代投、代运营、软件续费。 |
| 22:00-25:30 | 第五把刀：风险转移 | 学不会、没订单、店亏损、贷款、库存、退费难都在买方；卖方先把钱赚完。 |
| 25:30-28:30 | 五个反问 | 给观众一套可复制的判断清单。 |
| 28:30-30:00 | 收束 | 回扣开头：别问“这个项目听起来赚不赚钱”，先问“如果我失败，他已经赚了什么”。 |

## 钩子策略

这期不要用单纯猎奇钩子。最稳的是三段式：

```text
反常识判断
→ 合法边界
→ 给观众一个判断工具
```

原因：这个选题容易被观众误解成“所有卖课、加盟、高毛利都是骗局”。开头必须先承认灰度，再指出危险结构。

可用钩子方向：

| 类型 | 钩子 | 风险 |
|---|---|---|
| 反常识 | 有些人赚大钱，不靠骗你，而是靠你失败了他也能赚钱。 | 强，适合正片开场。 |
| 灰度边界 | 这个世界上最赚钱的小生意，很多都不违法，但你一进去就输。 | “小生意”容易泛化，后文要解释。 |
| 人物化 | 小人怎么在合法边缘赚大钱？答案不是胆子大，是风险从来不在他身上。 | “小人”有情绪张力，但略显标题党。 |
| 工具感 | 判断一个项目靠不靠谱，只问一句：如果我失败了，他已经从我身上赚了什么？ | 最有收藏价值，适合结尾回扣和封面。 |
| 场景化 | 9块9体验课、免费鸡蛋、低价加盟、AI副业课，它们卖的可能不是产品，而是筛选你。 | 信息密度高，适合前 30 秒。 |
| 悬念 | 为什么有些课程越多人学不会，卖课的人反而越赚钱？ | 适合 B 站标题。 |
| 边界声明 | 这期不是教你骂卖课的人，而是教你看懂一门生意的利润和风险。 | 稳，但点击弱，适合开场第二句。 |

推荐开场版本：

```text
有些人赚大钱，不是因为他骗术多高明，
而是因为整门生意从设计那一刻起，
就保证了：你成功，他赚钱；你失败，他也赚钱。

这就是很多信息差生意最隐蔽的地方。
它不一定违法，甚至看起来很正规：
有合同、有老师、有总部、有成功案例。
但问题是，卖方知道真实成本、成功率和退出机制，
而你只看见了一个被精心剪出来的未来。
```

备选标题：

- 小人怎么在合法边缘赚大钱？
- 你失败了，他为什么还能赚钱？
- 免费课、低价加盟和保过班的共同秘密
- 信息差生意：最赚钱的不是产品，是筛选你
- 判断一个项目靠不靠谱，只问这 5 个问题

封面短句：

- 你失败，他也赚
- 合法边缘的生意
- 免费不是福利
- 成功案例不是概率
- 先问他赚什么

## 去 AI 味规则：用真实案例制造“我懂了”

这期的危险不是信息不够，而是太容易被写成安全教育课。成片必须让观众产生一种成年人式的顿悟：

> 原来这些项目不是靠一句假话骗人，而是靠一套很顺滑、很正常、甚至看起来合法的商业流程，让我自己一步步走进去。

写作顺序改为：

```text
真实场景
→ 我们以为它在卖什么
→ 它实际在筛选/绑定/收费什么
→ 这个结构为什么让人容易相信
→ 最后抽象成一句判断工具
```

不要反过来写成：

```text
概念定义
→ 心理学名词
→ 行业分类
→ 案例
```

每 3-4 分钟至少一个可复述案例。案例要简单到观众能讲给爸妈听：

- 9.9 体验课不是福利，是在测谁愿意听完直播、加群、冲动付款。
- “包就业”不是先给你工作，而是先让你相信自己离工作只差一门培训。
- “1 元鸡蛋”不是便宜，是老人进入微信群和私域直播间的门票。
- “政府扶持加盟”如果写不进合同，就只是成交现场的氛围道具。
- 达人探店如果本人没体验过，所谓真实评价可能只是广告脚本。

小Lin式落法：

- 先有一个观众见过的场景。
- 再说“这里真正厉害的地方不是 X，而是 Y”。
- 最后给一句能截图的工具句。

示例开场加强版：

```text
你刷到过这种东西吗？
9块9体验课，老师说三天学会 AI 剪辑；
1块钱领鸡蛋，顺便听个健康讲座；
奶茶加盟说总部扶持，今天签还能拿政府补贴名额；
招聘软件上写着高薪兼职，面试完却说你能力差一点，先培训。

这些东西最可怕的地方，不是它们一眼假。
恰恰相反，它们常常看起来很正常：
有直播、有老师、有合同、有成功案例，甚至有一群人在现场下单。

但我们今天只问一个问题：
如果最后我没赚到钱，他已经从我身上赚了什么？
```

## 行业素材取舍

30 分钟不能把所有行业平均摊开，否则会变成百科。建议只做 6 个主案例，其余做快闪清单。

主案例优先级：

1. AI / 剪辑 / 配音 / 副业课：和我们账号、观众、当前环境最贴近。
2. 餐饮加盟：设备、原料、装修、选址、倒闭回收链条完整，视觉好做。
3. 保健品 / 养老会销：免费礼物、情感陪伴、恐惧销售，情绪冲击强。
4. 考证 / 包就业 / 培训贷：能解释“确定性幻觉”和合同陷阱。
5. 自媒体 / 电商 / 供应链培训：能解释“把你装进他的系统”。
6. 情感 / 婚恋 / 家长教育：能解释焦虑如何被产品化。

快闪清单：

- 金融投顾、虚拟币、外汇。
- 医美减肥、预付卡。
- 技术安装、开源项目包装。
- 私董会、高端社群。
- 出海、跨境、Web3。

## 视觉设计原则

每 10-20 秒一个视觉支撑。长视频最低配置：

- 章节标题卡：6-8 张。
- 公式图：信息差公式、变现路径公式、风险转移图。
- 漏斗图：免费内容到高价产品。
- 对比表：买方看到什么 / 卖方知道什么。
- 行业卡片：每个行业一张“卖什么、藏什么、风险在哪”。
- 合同小字动画：退费条件、指定供应链、收益不写进合同。
- 五问清单卡：结尾给观众截图保存。

## 小Lin式高级感：视听节奏层

本项目已有两条小Lin参考：

- `reference/商业金融书单/analysis.md`：10 分钟，116 个镜头切换，平均 5.2 秒/镜。适合“个人体验 + 可信推荐”。
- `reference/小Lin-日本财团/analysis.md`：14 分钟，375 个镜头切换，平均 2.24 秒/镜。更适合本期这种“商业结构揭秘”。

本期要参考第二条：用观众熟悉的表层现象，揭开背后一套结构。

```text
你见过的现象
→ 原来它们背后是同一套生意结构
→ 用一个很简单的比喻把结构讲懂
→ 用真实案例证明这不是编的
→ 回到观众自己怎么判断
```

### 开场 60 秒视听设计

不能只有口播。开场必须像“秘密档案被翻开”：

| 时间 | 口播功能 | 画面 | 节奏 |
|---:|---|---|---|
| 0:00-0:04 | 熟悉场景 1 | 手机刷到 9.9 AI 剪辑课，价格标签弹出 | 快切，低频 BGM 进入 |
| 0:04-0:08 | 熟悉场景 2 | 老人领鸡蛋/健康讲座剪影，群聊气泡 | 快切 |
| 0:08-0:12 | 熟悉场景 3 | 奶茶加盟展、设备、签合同手部特写 | 快切 |
| 0:12-0:18 | 熟悉场景 4 | 招聘 App 高薪兼职 → 培训贷合同 | 快切后停顿 |
| 0:18-0:25 | 第一反转 | 黑底大字：它们不一定一眼假 | 音乐降一拍，留白 |
| 0:25-0:38 | 核心判断 | 买方看到什么 / 卖方知道什么 对比卡 | 卡片推进 |
| 0:38-0:52 | 工具句 | “如果我失败了，他已经赚了什么？” | 文字逐字出现 |
| 0:52-1:00 | 预告结构 | 5 把刀：筛选、身份、案例、收费、风险 | 五张卡片依次翻开 |

### 镜头密度

- 开场 0-30 秒：1.5-2.5 秒一切。
- 案例叙述段：3-5 秒一切。
- 工具句 / 结论卡：允许 1-2 秒停顿，让观众“咽下去”。
- 30 分钟长片不能全程 2 秒一切，会疲劳；只在钩子、转折、案例快闪处加速。

### 音乐和停顿

音乐不是热闹，是“秘密感”和“价值感”的底色。

- BGM：低音量、持续、克制；偏商业纪录片 / 数据揭秘 / 轻悬疑，不用搞笑音效。
- 转折前停顿：每个关键句前后留 0.4-0.8 秒。
- 工具句停顿：念完“他已经赚了什么”后，留 0.8-1.2 秒，再进下一段。
- 不要用密集音效制造廉价感；卡片翻开、白闪、数字 ticker 可少量配 tick。

### 卡片系统

这期需要固定一套卡片语言，让观众感觉“我在看一套案卷”：

| 卡片 | 内容 | 视觉 |
|---|---|---|
| 案例卡 | 行业 + 入口价 + 后续费用 | 深底、白字、红色风险标签 |
| 利润链卡 | 免费体验 → 入门课 → 高阶课 → 工具/设备 | 横向箭头 |
| 买卖双方卡 | 买方看到 / 卖方知道 | 左右分屏 |
| 合同小字卡 | 退款条件、指定供应链、收益不写入合同 | 放大镜动画 |
| 五问卡 | 结尾判断工具 | 可截图保存 |

### 高级感的本质

高级感不是“说得复杂”，而是：

- 每个抽象判断都有画面证据。
- 每个行业案例都有统一卡片格式。
- 每个转折都用停顿和视觉留白承接。
- 每个章节都给观众一个“我懂了”的简单模型。

本期的观众记忆点只保留一个：

> 不是问它能不能赚钱，而是问我失败时它已经赚了什么。

## 口播语气

采用并肩式表达：

- 多用“我们”，少用“你怎么这么傻”。
- 不把观众放在被教育位置。
- 先承认合理性：高毛利、卖课、加盟不天然等于诈骗。
- 再指出关键差异：是否透明、是否可验证、是否把失败风险转嫁给买方。

## 关键金句储备

- 免费不是福利，是筛选器。
- 他们卖的不是课程，是一个想象中的你。
- 成功案例不是概率，截图不是财报，营业额不是净利润。
- 第一笔钱常常不是成交，而是入场券。
- 如果你失败了，他仍然赚完了钱，这个项目就要格外小心。
- 真正该问的不是“别人赚没赚到”，而是“失败者去哪了”。
- 合同里没有的承诺，最好当它不存在。
- 不要只看价格，先看完整费用链。
- 不要只问能赚多少，先问退出成本是多少。

## 最终交付模板

等正式文案进来后，输出以下文件：

```text
projects/<slug>/brief.md
projects/<slug>/script.md
projects/<slug>/storyboard.md
projects/<slug>/asset-list.md
projects/<slug>/titles.md
projects/<slug>/fact-check.md
```

其中 `fact-check.md` 单独放：

- 需要核验的监管案例。
- 可引用的官方链接。
- 不能直接断言的高风险表述。
- 需要改成“可能 / 常见 / 部分案例中”的地方。

## 成片验收

- 1 分钟内说清主结论。
- 3 分钟内让观众知道这期和自己有什么关系。
- 每个抽象概念后都有例子。
- 每个主案例都能回答：卖什么、为什么好卖、真正利润在哪、风险谁承担。
- 结尾给出五个可复制问题，而不是只输出情绪。
