# 主案例卡片

用途：给 30 分钟正片提供真实案例、口播素材、卡片设计和分镜依据。

注意：本片重点不是“已经违法的诈骗案例”，而是“合法外衣下的不对称生意”。官方案例只负责证明这些链条在现实中确实存在；正片主线要讲更常见、更灰、更难报警的版本。

每张卡都按同一套结构：

```text
熟悉入口
→ 买方看到什么
→ 卖方真正赚什么
→ 风险怎么转移
→ 结构拆解
→ 画面怎么拍
```

## Case 01：AI / 剪辑 / 配音副业课（合法外衣：技能培训）

### 熟悉入口

9.9 元体验课、免费直播、AI 剪辑训练营、配音接单课、短视频代运营陪跑。

常见话术：

```text
零基础也能学。
每天一小时，学完就能接单。
AI 时代，一个人就是一个团队。
现在不学，以后就被淘汰。
```

### 买方看到什么

- 低价入门，不贵。
- 学员收益截图。
- 老师展示 AI 工具几分钟做出成片。
- 群里有人说“已经接到第一单”。
- 页面把它包装成一次技能投资。

### 卖方真正赚什么

- 体验课只是筛选器。
- 正价课、高阶陪跑、接单营、个人 IP 训练营才是主收入。
- 后续可能继续卖素材库、提示词库、软件会员、API 额度、数字人、剪辑工具、投流服务。
- 学员没接到单，也不影响卖方已经收完课程费和工具费。

### 风险怎么转移

学员承担：

- 学不会。
- 做出来的作品卖不出去。
- 平台红利消失。
- 接单价格极低。
- 继续购买工具和陪跑。

卖方承担：

- 广告投放成本。
- 直播和销售团队成本。

关键判断：

```text
课程能不能赚钱，不看最好学员，而看普通学员扣掉工具、时间、平台抽成后的中位数收入。
```

### 结构拆解

灰色版本不一定违法，因为它确实可能交付课程。

但它最值得警惕的地方是：课程质量不是商业模型的唯一核心，销售漏斗才是。

```text
免费直播
→ 9.9 体验
→ 1999 入门课
→ 6999 陪跑
→ 软件 / API / 素材 / 投流
```

### 画面设计

- 手机刷到“AI 剪辑副业课”的重构直播间。
- “9.9”价格标签放大。
- 学员收益截图被打上“最好案例？”标签。
- 漏斗图：免费直播到高阶陪跑。
- 卡片标题：`不是卖课，是筛选动作漏斗`。

### 口播落点

```text
页面上写的是 9.9 低价体验。
但对卖方来说，9.9 的作用不是赚钱，是记录谁付款、谁留资、谁进群、谁听完整场转化课。
```

## Case 02：招聘转培训 / 培训贷（合法外衣：岗前培训）

### 真实锚点

最高人民法院 2026 年发布的典型案例中，有“以招聘为幌子诱导付费培训实施诈骗”的案例。法院披露，相关人员以知名平台稳定兼职为诱饵，发送虚假兼职盈利图片，虚构“边学边赚钱”“轻松覆盖学费”等说法，诱骗求职人员购买在线课程参加“入职培训”。来源：最高人民法院《人民法院依法惩治电信网络诈骗等侵犯财产犯罪典型案例》。

正片不要只讲这个已经入刑的版本，而要讲更常见的灰色版本：培训可能真实存在，岗位也可能只是“推荐就业”，但求职者是在招聘语境下被转化成培训消费者。

### 熟悉入口

招聘 App 上的高薪兼职：

```text
不限经验。
居家办公。
月入过万。
名企项目。
学完安排接单。
```

### 买方看到什么

- 自己是来找工作的，不是来消费的。
- 对方像正规公司，有面试、有岗位、有 HR。
- 面试话术把“能力差一点，培训一下就能入职”放在招聘流程后半段。
- 分期付款把一次性培训费拆成每月账单。

### 卖方真正赚什么

- 培训费。
- 分期贷款渠道佣金。
- 招生提成。
- 简历和个人信息。
- 有时还可以让学员做低价外包任务。

### 风险怎么转移

求职者承担：

- 没有真正岗位。
- 培训质量差。
- 背上贷款。
- 退款被拖延或推诿。

卖方承担：

- 招聘广告和销售成本。

### 结构拆解

这一类的关键，是把“求职流程”切换成“培训消费流程”。

```text
我来赚钱
→ 你说我差一点
→ 我先交钱补能力
→ 工作没来，债先来了
```

### 画面设计

- 招聘 App 页面：`不限经验 / 月入过万`。
- 面试聊天气泡：`你很适合，就是基础差一点`。
- 分期付款按钮。
- 法院案例资料卡：`招转培 / 学费 2200 万余元`。
- 风险转移图：`岗位承诺` 箭头变成 `培训账单`。

### 口播落点

```text
招转培的关键结构，是求职入口后面接上培训合同和分期账单。
```

## Case 03：餐饮加盟 / 快招项目（合法外衣：品牌授权）

### 真实锚点

市场监管总局 2025 年发布的直播电商典型案例中，有招商项目通过直播推介时宣传“政府帮扶”“五免政策”、名额紧缺、合作股东和战略伙伴，夸大项目预期收益，并被监管部门处罚。来源：市场监管总局《第三批直播电商领域典型案例》。

正片重点不是“虚假政府扶持”这个违法点，而是加盟灰色结构：就算品牌授权是真的、合同也是真的，加盟者仍可能在设备、装修、原料、系统、推广里被持续收费。

### 熟悉入口

奶茶、小吃、预制菜、无人售货柜、纯外卖店加盟。

常见话术：

```text
总部扶持。
区域保护。
今天签有内部价。
设备、选址、装修、开业推广一条龙。
别人加盟 30 万，你这里 2 万就能拿名额。
```

### 买方看到什么

- 低加盟费。
- 销售页展示总部、样板店、签约桌和门店效果图。
- 门店效果图很漂亮。
- 直播间有人下单。
- “政府扶持”“内部名额”“区域保护”会出现在销售页、直播间和合同沟通里。

### 卖方真正赚什么

- 加盟费。
- 设备差价。
- 装修指定合作方。
- 首批原料。
- 收银系统。
- 广告代投。
- 后续原料持续供货。

### 风险怎么转移

加盟者承担：

- 房租。
- 人工。
- 客流不足。
- 平台抽成。
- 食材损耗。
- 区域竞争。
- 店铺倒闭。

卖方承担：

- 招商广告。
- 样板店和直播销售成本。

### 结构拆解

加盟项目表面卖“品牌”，实际常常卖一整套供应链。

```text
低加盟费
→ 设备
→ 装修
→ 原料
→ 系统
→ 推广
→ 复购供货
```

### 画面设计

- 加盟展 B-roll：展位、灯箱、签约桌。
- 设备价格牌：市场价 / 总部价对比。
- “政府扶持”字样被红框圈出，再切到“合同里没有”。
- 利润链卡：`加盟费只是入口`。
- 门店收益表从“营业额”切到“净利润”。

### 口播落点

```text
餐饮加盟不能只问加盟费多少。
真正该问的是：开店以后，有多少东西只能从它那里买。
```

## Case 04：老年保健品 / 免费鸡蛋 / 私域直播（合法外衣：健康服务）

### 真实锚点

市场监管总局 2025 年公布的七起老年人药品、保健品虚假宣传典型案例中，概括出“免费体验—制造问题感—虚假宣传—高价销售”的链条，并提到“1 元购 10 枚鸡蛋”成为一些不法商家引流老年群体的惯用手段。来源：市场监管总局《七起老年人药品、保健品虚假宣传典型案例》。

正片要讲的是更常见的灰色版本：健康讲座、会员服务、普通食品或保健品本身可能合法，但销售流程通过到店、登记、加群、检测、回访和复购提醒，让老人难以独立判断价值。

### 熟悉入口

```text
1 元鸡蛋。
免费体检。
免费旅游。
健康讲座。
微信群直播。
专家连线。
```

### 买方看到什么

- 礼物很小，不像骗局。
- 销售人员很热情。
- 群里有人发布使用反馈或复购截图。
- 检测仪器给出“数字结果”。
- 产品被包装成“调理”“改善”“修复”。

### 卖方真正赚什么

- 高价保健品。
- 疗程套餐。
- 会员复购。
- 私域直播反复销售。
- 转介绍。
- 老年人个人信息。

### 风险怎么转移

老人承担：

- 买到高价低效产品。
- 延误正规治疗。
- 情感依赖。
- 子女反对后家庭冲突。
- 个人信息被继续营销。

卖方承担：

- 鸡蛋、场地、讲座、销售团队成本。

### 结构拆解

鸡蛋不是福利，是门票。

```text
小礼物
→ 到店
→ 注册
→ 加群
→ 直播
→ 异常提示
→ 高价套餐
```

### 画面设计

- 手拿鸡蛋、登记表、微信群二维码。
- 免费检测仪数值飙红。
- “调理 / 改善 / 修复”三个词浮现，再打问号。
- 私域直播间重构。
- 案例资料卡：`1 元购 10 枚鸡蛋`。

### 口播落点

```text
你以为它在送鸡蛋。
它其实在记录：谁到店，谁登记，谁加群，谁听讲座，谁继续购买。
```

## Case 05：直播间展示与实际交付不一致（合法外衣：正常发货）

### 熟悉入口

直播带货、私域团购、健康产品、学习用品、加盟样品、课程工具包、设备耗材。

常见话术：

```text
直播间同款。
拍一号链接。
今天拍下多送一份。
收到不满意可联系客服。
批次不同不影响使用。
```

### 买方看到什么

- 直播间展示了实物。
- 页面有价格、套餐图和下单入口。
- 物流确实发货。
- 到手后，售后给出批次、规格、赠品、拍摄角度等解释。

### 卖方真正赚什么

- 直播间成交佣金。
- 货品差价。
- 套餐升级。
- 补差价。
- 售后退货门槛。
- 私域复购。

### 风险怎么转移

买方承担：

- 直播画面与实际交付的核对成本。
- 退货运费。
- 举证截图。
- 售后沟通时间。
- 补差价。
- 产品已经拆封或使用后的退换限制。

卖方承担：

- 发货成本。
- 一部分退换货。
- 售后客服成本。

### 结构拆解

灰色版本的关键在于：它不一定不发货。

它可能确实发了一个东西，也可能确实有售后入口。问题是购买前展示、下单页文字、实际收到、售后解释没有被放进同一张清单里核对。

```text
直播间：拍到的样品
页面：写到的套餐
到手：收到的实物
售后：解释差异的口径
```

### 画面设计

- 三列对照：直播间拍到 / 页面写到 / 实际收到。
- 第四列浮出：售后解释口径。
- 红线标出无法逐项对应的地方。
- 退款路径只作为后续，不作为主视觉。

### 口播落点

```text
看到直播间展示，别只问它有没有发货。
先把镜头里的东西、页面上的东西、到手的东西逐项对齐。
```

## Case 06：平台型供应链副业（合法外衣：一站式服务）

### 熟悉入口

无货源电商、跨境电商、AI 短剧、自媒体代运营、直播带货、剪辑接单平台、外贸陪跑。

常见话术：

```text
你不用找货。
总部派单。
我们提供素材和模板。
你只负责执行。
平台、仓库、物流、收款全都帮你接好。
```

### 买方看到什么

- 门槛变低。
- 不用自己找客户。
- 不用囤货。
- 页面展示后台、订单、货源、物流和收益截图。
- 有后台、有订单、有收益截图。

### 卖方真正赚什么

- 软件订阅。
- ERP 费用。
- 货源差价。
- 物流差价。
- 仓储费。
- 广告充值返点。
- 订单抽成。
- 提现手续费。
- 账号注册和申诉服务。

### 风险怎么转移

学员承担：

- 平台封店。
- 侵权。
- 退款。
- 广告亏损。
- 物流延迟。
- 账号被冻结。
- 商品同质化。

卖方承担：

- 搭建系统和招商获客成本。

### 结构拆解

它不是教你做生意，而是把你装进它的生意。

```text
课程
→ 系统
→ 货源
→ 物流
→ 广告
→ 订单
→ 抽成
```

### 画面设计

- 后台订单数字滚动。
- 货源、物流、广告、ERP 四个模块围住学员。
- “你只负责执行”变成“你承担亏损”。
- 系统锁定图：退出会丢数据、账号、保证金。

### 口播落点

```text
当一个项目说“你什么都不用管”的时候，要反过来问：
那我到底控制什么？又承担什么？
```

# 六张卡合成的大模型

把商品名字拿掉，现金流路径几乎一样：

```text
低门槛入口
→ 结果承诺
→ 成功案例
→ 分层收费
→ 系统绑定
→ 退出困难
```

对应视频里的总卡片：

```text
它们卖的不是同一种产品，
但它们常常赚同一种钱：
筛选费、入场费、升级费、工具费、供应链差价、退出成本。
```
