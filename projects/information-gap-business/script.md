# 正片口播稿 v0.3

范围：30 分钟正片初稿。

原则：以用户提供的两份附件为主素材。网络案例只补证据，不改主线。全稿禁止用读心术解释成交，只写可看到、可听到、可核验的动作和信息差。

预估时长：约 30 分钟。

## 0:00-1:30 开场：你失败了，他也赚

你刷到过这种东西吗？

9 块 9 的体验课，老师说，三天学会 AI 剪辑，学完就能接单。

一块钱领鸡蛋，顺便听个健康讲座。签到表上要写姓名、年龄、电话，旁边还有微信群二维码。

奶茶加盟展上，总部说现在有扶持名额。今天签约，设备、选址、装修、开业推广，都能一起安排。

还有招聘软件上的高薪兼职：不限经验，居家办公，月入过万。你去面试，聊到最后，对方说，你基础差一点，先培训，之后再安排项目。

【画面：四个场景快切。9.9 直播课、鸡蛋和登记表、加盟展签合同、招聘 App 到培训合同。每个 2 秒左右。】

这些东西最麻烦的地方，不是它们一眼假。

恰恰相反，它们常常有一套完整材料。

有直播，有老师，有合同，有总部，有成功案例，有付款链接，也有一群人正在下单。

所以这期视频，我们先不问：它到底是不是骗局。

我们只问一个更具体的问题：

如果最后我没赚到钱，它已经从我身上赚了什么？

【画面：黑底大字卡。“如果我失败了，它已经赚了什么？”字逐个出现。停 1 秒。】

这个问题一问出来，很多生意的现金流就会清楚。

免费课，可能不是福利，而是筛选入口。

成功案例，可能不是整体结果，而是销售素材。

低价加盟，可能不是优惠，而是把你带进设备、原料、装修和推广的收费链。

直播间展示，可能不是假货，而是展示品、页面说明和到手品对不上。

这期我们就拆一件事：

为什么有些项目不需要等你成功，它在你付款、买工具、签合同、进系统的时候，就已经把钱赚走了。

【画面：标题卡。你失败，他也赚。BGM 稍起，进入正片。】

## 1:30-2:50 先划边界：不是所有高毛利都是诈骗

先说清楚，卖课、加盟、高毛利，本身不等于诈骗。

这个边界一定要先划出来，不然这期就会变成骂街。

一个东西贵，但它把内容、成本、收益口径、退款条件、后续费用都说清楚，那它就是正常生意。买方可以比较价格，也可以不买。

第二层，是信息极不对称的生意。产品可能是真的，课程也可能真的存在，加盟品牌也可能真的有门店。但它会把最关键的信息放到后面。

比如它不说普通学员扣掉工具费之后收入多少，只说最好那个学员月入三万。

它不说加盟后的真实净利润，只给你看开业当天排队的画面。

它不说后面还要买工具、原料、系统、广告，只把第一笔钱放到最大、最显眼的位置。

第三层，是违法营销。案例、功效、资质、销量、官方关系，开始出现虚构。

第四层，才是刑事诈骗。从一开始就没有兑现能力，目的就是骗培训费、加盟费、投资款。

【画面：四层边界卡。正常生意 / 信息不对称 / 违法营销 / 刑事诈骗。第二层高亮。】

今天最值得拆的，是第二层。

因为现实里最常见的亏损，不一定来自一眼能报警的诈骗。

合同是真的。课也上了。群也建了。总部也发货了。设备也寄给你了。

可你就是亏了。

亏完以后再看账单，它的收入不只来自“你成功以后分成”。

它已经从学费、加盟费、设备差价、原料、软件、广告代投、会员续费里收过一轮。

【画面：卖方收入卡。学费、加盟费、设备差价、原料利润、广告管理费、软件续费、订单佣金依次亮起。】

所以这期不围绕“它违不违法”讲。

我们围绕另一个更实用的问题讲：

它把哪些关键信息放到了付款之后？

## 2:50-4:10 第一层机器：免费不是福利，是筛选入口

先看第一层：免费和低价。

免费直播，9.9 元体验课，免费鸡蛋，免费体检，免费选址，免费安装。

这些东西在页面上写成福利、体验、扶持或赠品。

但在很多信息差生意里，它更像筛选入口。

【画面：漏斗图。免费直播 / 9.9 体验 / 加微信 / 进群 / 正价课 / 高阶陪跑。】

它筛的不是“心里怎么想”。

它筛的是动作。

谁点进直播间。

谁停到讲价环节。

谁留下手机号。

谁加微信、进群、填表。

谁支付 9.9 元。

谁听完一整场转化课。

【画面：行为标签卡。点击 / 停留 / 留资 / 加群 / 付款 / 听完。】

这些动作，比一句“我感兴趣”更有用。

因为它们能把人分层：

只看一眼的人，放在最外层。

留下联系方式的人，进入私域。

付过小钱的人，进入正价课销售。

听完整场的人，进入高阶陪跑、会员、工具、设备、代理的销售链。

所以 9.9 元本身不是重点。

重点是，一个人完成了“付款 + 留资 + 听课 + 进群”这几个动作，卖方后面就可以反复触达他。

【画面：联系方式从一个点变成多条触达线：电话、微信、群直播、朋友圈、私信、短信。】

这也是为什么很多课程第一节特别便宜，甚至免费。

低价课不是终点，它是入口。

真正的链条是：

免费体验，基础课，高阶课，陪跑营，会员，工具，API，素材，设备，指定原料，广告代投，订单抽成，续费维护。

第一笔费用，有时候不是成交。

是入场券。

【画面：收费链横向展开。每出现一层，BGM tick 一下。】

## 4:10-5:35 成功案例不是概率

这个地方最容易说虚。

所以我们只看屏幕上出现了什么。

直播间里，老师先展示一个销售页直接写出来的问题。

比如：AI 剪辑现在能不能接单。

比如：孩子成绩上不去，家长还能做什么。

比如：同样是开店，为什么别人一个月回本，你半年还亏。

然后画面会切到案例。

宝妈，零基础，两周接商单。

加盟商，一个月回本。

老人，吃完以后复购。

学员，报班之后工资涨了。

【画面：成功案例截图墙。随后盖章：最好案例？整体概率？净利润？】

这些案例不一定每一个都是假的。

真正的问题是，它们只展示了局部。

不展示一共招了多少人。

不展示成功案例占比多少。

不展示成功者原来有什么资源。

不展示收入是营业额还是净利润。

不展示广告费、设备费、退款、税费扣掉之后还剩多少。

也不展示没做成的人后来怎么样了。

所以看到案例，不要先问：这张图是真的假的？

更好的问题是：

这张图代表整体概率吗？

【画面：黑底大字。成功案例不是概率。截图不是财报。营业额不是利润。】

## 5:35-6:50 真实一点的例子：免费鸡蛋不是鸡蛋

我们拿一个特别简单的例子说。

一块钱十个鸡蛋。

这个东西很小，小到不像一门生意。

但你顺着流程往后看，就会发现它的结构很完整。

第一步，不是卖保健品。

第一步是到店。

第二步，登记。

姓名、电话、年龄、身体状况、家庭住址，至少会留下其中几项。

第三步，加群。

以后不用每次把人叫到现场，直播间、小程序、微信群都可以继续触达。

第四步，讲座。

主题通常不是产品参数，而是血管、三高、结节、睡眠、免疫力这些具体健康问题。

第五步，检测。

仪器一测，屏幕出现红色数字、异常提示、上升箭头，再配上“幸亏发现得早”这类话术。

第六步，产品。

普通食品、保健品、理疗仪、疗程套餐，开始出现。

【画面：鸡蛋 → 登记表 → 微信群 → 讲座 → 检测仪红色数字 → 产品套餐。做成流程图。】

你看，鸡蛋不是鸡蛋。

鸡蛋是门票。

它换来的不是十个鸡蛋的成交。

而是到店、登记、加群、听讲座、接受检测、进入复购环境。

这就是筛选入口。

## 6:50-8:10 为什么这种东西很难防

这种模式难处理，是因为它经常披着服务的外衣。

销售人员不一定一上来就逼单。

他可能每天发问候。

记生日。

组织活动。

在群里叫叔叔阿姨。

给你发检测报告。

提醒你参加下一场直播。

这些动作本身未必违法。

但它们会把一次交易，变成长期触达。

所以子女如果只说“这个东西不值钱”，往往解决不了问题。

因为账面上卖的是一盒产品。

流程里交付的还有问候、活动、群直播、复购提醒和专人跟进。

【画面：产品卡渐隐，变成“问候 / 活动 / 群直播 / 复购提醒 / 专人跟进”。】

这也是为什么我们这期不能简单说“别贪小便宜”。

太粗糙了。

很多时候，起作用的不是某个抽象标签，而是一套可复制流程：

低门槛入口。

留下联系方式。

展示最好案例。

给出限时条件。

卖第一笔正价产品。

再卖工具、设备、原料、会员、续费。

【画面：回到总模型。免费/低价入口 → 留资/进群 → 成功案例 → 分层收费 → 系统绑定 → 退出困难。】

所以第一把钥匙很简单：

看到免费和低价，不要只问“我占了多少便宜”。

先问：

我接下来要留下什么信息？

我要进入什么群或系统？

后面还有哪些必须付款的环节？

【画面：章节收束卡。问题 1：免费入口后面，接着收什么？】

## 8:10-12:30 第二层：卖的不是产品，是结果承诺

接下来进入第二层。

很多项目表面卖的是课程、调料、机器、账号、系统。

但销售页真正摆在最前面的，通常不是产品参数。

它摆的是一个结果标签。

AI 时代第一批吃红利的人。

把爱好变成事业。

建立被动收入。

不再给别人打工。

独立女性。

城市合伙人。

为孩子抢占未来。

传承老祖宗智慧。

【画面：结果标签墙。每个标签像商品吊牌一样挂出来，下面标注对应行业：卖课、加盟、亲子、养生、婚恋、供应链副业。】

这些词不能直接证明项目有问题。

问题在于，销售页常常把“结果标签”放在最显眼的位置，把“达到这个结果需要什么条件”放在很后面。

比如 AI 剪辑课。

页面第一屏写的是：

零基础也能学。

每天一小时。

学完就能接单。

一个人就是一个团队。

【画面：重构销售页。左边是“零基础 / 接单 / 红利”，右边浮出工具费、素材版权、平台抽成、客户来源、交付标准。】

但真正决定这件事能不能跑通的，不只有课程。

还有几个更硬的东西：

你做出来的作品能不能达到客户交付标准。

客户从哪里来。

平台接单价格是多少。

工具会员、API、素材库每个月多少钱。

同类服务的人有多少。

退款和陪跑条件怎么写。

这些信息如果不一起出现，买方看到的就是一个结果标签，而不是完整生意。

【画面：结果标签卡翻面，背面是五项条件：客户来源 / 交付标准 / 工具成本 / 平台价格 / 退款条件。】

餐饮加盟也是一样。

页面第一屏写：

总部扶持。

区域保护。

内部名额。

设备、选址、装修、开业推广一条龙。

但开店这件事，最后算账的时候不是只算加盟费。

还要算房租、人工、水电、损耗、平台抽成、外卖满减、原料复购、设备维修、广告投放。

【画面：加盟费 2 万放大。随后账单展开：房租、人工、设备、装修、原料、推广、平台抽成。加盟费从最大数字变成账单里的一行。】

所以第二把钥匙是：

看到任何结果承诺，不要只看它承诺你变成什么。

要问：

为了达到这个结果，我必须持续投入哪些东西？

这些投入，是不是都只能从卖方那里买？

【画面：章节收束卡。问题 2：结果承诺背后，必须投入什么？】

## 12:30-17:00 第三层：成功案例不是概率

第三层，是成功案例。

几乎所有信息差生意都会展示案例。

卖课展示学员收益截图。

加盟展示门店排队视频。

保过班展示上岸名单。

保健品展示反馈截图。

直播间展示购买人数和晒单。

【画面：五类案例墙。每张截图上盖半透明标签：收益截图 / 排队视频 / 上岸名单 / 反馈截图 / 晒单。】

案例本身不等于假。

但案例也不等于概率。

一个项目最该拿出来的，不是单个最好案例，而是四个数字。

第一，总共有多少人参加。

第二，有多少人达到页面展示的结果。

第三，中位数结果是多少。

第四，扣掉成本以后还剩多少。

【画面：四个空白数据框。总人数、达标人数、中位数、净结果。成功案例截图被缩到左下角。】

比如一个副业课说，有学员月入三万。

这句话本身缺四个口径。

三万是收入还是利润？

有没有扣掉广告费、工具费、平台抽成、退款？

这个学员原来有没有账号、客户、团队、资源？

同一期一共有多少学员？

【画面：月入 30000 大字。每问一句，数字旁边多一个扣减项：广告费、工具费、抽成、退款、税费。最后变成“净结果：未知”。】

再比如加盟项目说，一个月回本。

你要把“营业额”和“净利润”分开。

营业额是收银机进了多少钱。

净利润是扣掉房租、人工、食材、平台抽成、活动补贴、损耗以后还剩多少钱。

很多项目展示的是开业当天排队。

但门店能不能活下来，要看三个月、六个月、一年后的净现金流。

【画面：开业当天排队视频定格，然后时间轴拉到 3 个月、6 个月、12 个月。每个节点下方出现净现金流表格。】

直播间带货和私域团购也一样。

页面写通过率 92%。

你要问：

这个通过率的样本是谁？

是不是只统计了全勤学员？

是不是排除了中途退课的人？

是不是只统计了某一批基础更好的人？

退款条件里有没有全勤、作业、模考、投递数量、服务费不退？

【画面：通过率 92% 被放进筛选漏斗。报名人数 → 开课人数 → 全勤人数 → 参加考试人数 → 通过人数。】

所以第三把钥匙是：

任何成功案例出现时，旁边都要补四个问题。

总人数是多少？

中位数是多少？

净结果是多少？

没达标的人去哪了？

【画面：黑底大字。成功案例不是概率。截图不是财报。营业额不是利润。停 0.8 秒。】

## 17:00-22:00 第四层：利润藏在第二层、第三层

第四层，是收费链。

很多项目第一笔钱不高。

9.9 元，99 元，199 元。

加盟费 2 万。

培训先分期。

免费选址，免费安装，免费检测。

但第一笔钱不代表完整成本。

【画面：第一笔费用卡片。随后镜头拉远，背后出现长长的后续费用链。】

在你给的两份素材里，有一条特别关键的链条：

免费体验。

基础课。

高阶课。

陪跑营。

会员。

工具。

API。

素材。

设备。

指定原料。

广告代投。

订单抽成。

续费维护。

【画面：费用链横向展开，超过屏幕宽度，镜头沿着链条移动。每一项下面标注“谁收钱”。】

这就是为什么要把“第一笔钱”和“完整费用链”分开。

第一笔钱负责让你进来。

后续费用负责让卖方持续收钱。

AI 副业课里，课程费只是第一层。

后面可能还有工具会员、素材库、提示词库、API 额度、数字人、接单平台会员、投流服务。

餐饮加盟里，加盟费只是第一层。

后面可能还有设备、装修、首批原料、收银系统、广告代投、后续供货。

平台型副业里，课程费只是第一层。

后面可能还有 ERP、货源差价、物流差价、仓储费、广告充值返点、订单抽成、提现手续费。

【画面：三列对照。AI 副业课 / 餐饮加盟 / 供应链副业。每列从第一笔费用展开到后续费用。】

现在看招聘转培训。

这个结构更直接。

买方原本打开的是招聘软件。

页面写的是：

不限经验。

居家办公。

月入过万。

学完安排接单。

【画面：招聘 App 页面重构。高薪兼职卡片被点击，切到面试聊天框。】

流程往后走，角色会发生切换。

第一步，求职。

第二步，面试。

第三步，对方说基础差一点。

第四步，推荐培训。

第五步，出现分期合同。

第六步，岗位变成“推荐就业”或者“接单机会”。

【画面：流程卡。招聘 → 面试 → 能力不足 → 培训合同 → 分期账单 → 推荐就业。中间用红线标出“流程切换点”。】

这里最关键的不是对方说了多少漂亮话。

关键是付款发生在工作之前。

买方原本是来获得收入，最后先承担了一笔支出。

如果项目没有兑现，卖方已经拿到了培训费、分期渠道佣金、招生提成和个人信息。

买方留下的是课程、贷款、退款条件和时间成本。

【画面：左右分屏。左边：卖方拿走培训费、渠道佣金、招生提成、个人信息。右边：买方留下贷款、课程、退款流程、时间成本。】

所以第四把钥匙是：

不要只问第一笔多少钱。

要把后面所有必须支付、可能支付、退出时损失的费用，全部列成一张表。

【画面：费用清单表格。当前价格 / 必须后续费用 / 可选升级费用 / 退出成本 / 谁收钱。】

## 22:00-26:30 第五层：风险被转移给买方

第五层，是风险转移。

一个项目到底靠不靠谱，可以问一句很硬的问题：

卖方赚不赚钱，是否依赖你最终成功？

【画面：黑底大字。卖方赚不赚钱，是否依赖你最终成功？停 1 秒。】

如果答案是依赖，那至少双方利益有一部分绑定。

比如你赚钱，平台抽成；你卖出货，总部抽佣；你接到订单，系统收服务费。

但如果答案是不依赖，就要格外小心。

你没学会，课程费已经收了。

你没接到单，工具费已经收了。

你店倒闭，设备和原料已经卖了。

你没就业，培训分期已经签了。

你没通过考试，退款条件还要逐条证明。

【画面：五张卡依次落下。没学会 / 没接单 / 店倒闭 / 没就业 / 没通过。每张卡下方对应卖方已收费用。】

风险转移不是一句抽象话。

它可以拆成一张表。

卖方拿走：

学费。

加盟费。

设备费。

原料差价。

软件费。

广告管理费。

订单佣金。

买方留下：

贷款。

库存。

房租。

平台规则。

时间成本。

退款流程。

账号风险。

【画面：风险转移表。左边金色“卖方拿走”，右边红色“买方留下”。】

供应链型副业最适合解释这个结构。

销售页会说：

你不用找货。

总部派单。

我们提供素材和模板。

平台、仓库、物流、收款全都帮你接好。

你只负责执行。

【画面：销售页重构。关键词逐个高亮：不用找货 / 总部派单 / 模板 / 仓库物流 / 只负责执行。】

但如果把这句话翻成控制权清单，就会变成：

货源，不在你手里。

物流，不在你手里。

广告账户，可能不在你手里。

订单系统，可能不在你手里。

素材、API、账号申诉、提现规则，也可能不在你手里。

你控制得越少，退出时能带走的东西就越少。

【画面：控制权清单。每一项从买方身边移到平台/总部一侧。最后买方只剩“执行”和“亏损”。】

所以当一个项目说“你什么都不用管”，不要只把它当成省事。

要反过来问：

我到底控制什么？

我到底承担什么？

如果退出，我能带走什么？

【画面：三问卡。控制什么 / 承担什么 / 退出带走什么。】

再看直播间交付。

很多时候，它甚至不需要隐藏条款。

直播间拍到的是一份材料。

下单页面写的是另一份材料。

你实际收到的，是第三份材料。

比如镜头里拍的是样品特写。

页面里写的是套餐图和规格表。

到手之后，售后解释成批次不同、拍摄角度、赠品调整、规格浮动。

这几句话单独看，都可能成立。

但问题在于：购买前，它没有把“拍到的、写到的、会收到的”放在同一张清单里核对。

【画面：三列材料。左列“直播间拍到”：样品特写、主播演示、下单口令。中列“页面写到”：套餐图、规格表、售后入口。右列“实际收到”：批次不同、赠品变更、补差价。三列之间出现无法对齐的红线。】

所以看到直播间展示，不要只问它有没有发货。

要问：镜头里的东西，页面上的东西，到手的东西，能不能逐项对上？

【画面：展示品 / 页面 / 到手品 三张卡叠在一起，重合不了的地方标红。】

第五把钥匙是：

把风险写成两列。

卖方已经收了什么？

买方还承担什么？

如果买方失败，卖方是否已经赚钱？

【画面：章节收束卡。问题 5：我失败时，它已经赚了什么？】

## 26:30-30:00 五个问题：把项目拉回账面

最后，我们把整期视频收成五个问题。

这五个问题来自你提供的结构版素材。

它们不负责判断一个项目一定好或一定坏。

它们只负责把销售页拉回账面、合同和概率。

【画面：五问清单卡。每个问题单独占一屏，适合截图。】

第一，不算最好案例，全部学员或加盟商的中位数收入是多少？

注意，是中位数，不是最高值。

是全部人，不是精选案例。

是收入扣掉成本之后的结果，不是销售页上最大那张截图。

【画面：最好案例被放到右上角，中间出现一条人群分布线，标出中位数。】

第二，失败者占多少，失败的主要原因是什么？

如果一个项目只能展示成功者，却说不清失败者比例，那它展示的是广告素材，不是完整结果。

失败原因也要拆开。

是学不会。

是没流量。

是没客户。

是工具成本太高。

是平台规则变了。

是退款条件卡住了。

【画面：失败原因矩阵。学习 / 流量 / 客户 / 工具 / 平台 / 退款。】

第三，除了当前价格，未来必须支付的全部费用有哪些？

课程后面有没有工具。

加盟后面有没有设备、装修、原料。

系统后面有没有月费、抽成、提现手续费。

培训后面有没有分期利息。

售后口径里有没有“批次不同、赠品随机、拆封影响退换、补差价”。

【画面：完整费用链表格。当前价格只是第一列。】

第四，交付清单能不能逐项确认？

如果直播间展示的是 A，页面下单是不是也写 A？

如果页面写的是 A，到手是不是能按型号、规格、数量、重量、售后口径逐项核对？

如果售后说批次不同，这个范围购买前有没有列出来？

如果说赠品随机，随机池里到底有哪些？

【画面：展示画面、页面规格、到手实物、售后口径四张卡对齐。无法对应的行标红。】

第五，假如我完全没有赚到钱，你们已经从我身上赚了哪些钱？

这就是整期视频的主问题。

如果你完全没赚到钱，对方已经从学费、加盟费、设备、原料、软件、广告、贷款、续费里收了一圈。

那这个项目就不是单纯跟你一起赚钱。

它也在赚你进入系统时交出去的钱。

【画面：回到开场四个场景。9.9 课、免费鸡蛋、加盟展、招聘转培训。每个画面旁边出现“它已经赚了什么”。】

所以最后不要只问：

这个项目能不能赚钱？

先问：

如果我失败了，它已经从我身上赚了什么？

【画面：主标题卡回归。你失败，他也赚。音乐下降，停 1.2 秒。】

把这个问题带回去看 9.9 课、免费鸡蛋、低价加盟、招聘转培训、直播间交付。

很多东西就会从“机会”变成“账单”。

从“案例”变成“概率”。

从“扶持”变成“控制接口”。

从“直播展示”变成“交付清单”。

【画面：四组词翻面。机会→账单，案例→概率，扶持→控制接口，展示→交付清单。】

这不是让你否定所有课程、加盟、培训和副业。

而是付款前先做一件事：

把销售页和直播间里的展示，翻译成完整费用链、失败概率、交付清单和退出成本。

【画面：最终五问卡完整出现。停 5 秒，方便截图。】
