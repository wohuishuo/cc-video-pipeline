# 视觉与声音系统

目标：把“信息差生意”做成商业结构揭秘片，而不是安全教育 PPT。

参考：`reference/小Lin-日本财团/analysis.md` 的高密度结构揭秘感。

## 核心视觉隐喻

这期不是“诈骗名单”，而是“商业机器解剖”。

画面关键词：

```text
案卷
现金流
交付差异
筛选漏斗
系统绑定
风险转移
```

画面要反复出现同一组“内外两层”对照：

```text
外面：免费、低价、扶持、保过、派单
里面：筛选、分层、绑定、抽成、退出困难
```

## 色彩

主色：

- 背景：深暖黑 `#0f1115`
- 主文字：暖白 `#f3efe7`
- 警示红：`#d94a3a`
- 金色价值：`#d6a742`
- 冷蓝数据：`#4f8cc9`
- 暗绿系统：`#4f8f6a`

规则：

- 全片不要五颜六色。
- 每张卡只用一个强调色。
- 红色只用于风险、交付差异、隐藏费用。
- 金色用于“卖方赚什么”。
- 蓝色用于数字、官方案例、结构图。

## 字体与卡片

字体方向：

- 粗黑体。
- 字少、字号大。
- 不做花哨艺术字。

卡片统一结构：

```text
左上：CASE 01
主标题：AI 副业课
副标题：不是卖课，是筛选动作漏斗
三行信息：
入口：9.9 体验课
后续：陪跑 / 工具 / API / 素材
风险：学不会、接不到单，费用已付
```

卡片类型：

| 类型 | 用途 | 样式 |
|---|---|---|
| 案例卡 | 每个主案例登场 | 深底 + 编号 + 行业名 + 一句结论 |
| 对照卡 | 买方看到 / 卖方知道 | 左右分屏，中间竖线 |
| 漏斗卡 | 免费到高价 | 从宽到窄或从上到下 |
| 交付卡 | 直播间 / 页面 / 到手 / 售后 | 三列对照 / 红线无法对齐 |
| 金句卡 | 章节结论 | 黑底大字，留白 |
| 五问卡 | 结尾工具 | 可截图保存，整齐编号 |

## 镜头密度

30 分钟长片不能全程 2 秒一切，但关键段要有小Lin式密度。

| 段落 | 镜头密度 | 原因 |
|---|---:|---|
| 开场 0-30s | 1.5-2.5s/切 | 快速建立“我见过这些” |
| 主问题 30-90s | 4-6s/切 | 让核心问题停住 |
| 案例入口 | 2-4s/切 | 真实场景快切 |
| 结构解释 | 4-7s/切 | 给图表和关键数字停留时间 |
| 金句 / 工具句 | 6-9s/切 | 给截图卡和关键问题停留时间 |
| 五问结尾 | 5-8s/切 | 方便截图保存 |

验收线：

- 不允许连续 40 秒纯口播无视觉支撑。
- 每个抽象概念必须配卡片或图。
- 每个案例至少 1 张案例卡 + 1 张利润链/风险图。

## 音乐

音乐定位：低音量商业纪录片 / 轻悬疑 / 数据揭秘。

不要：

- 搞笑综艺音效。
- 短视频洗脑 BGM。
- 太热血的鼓点。
- 每个转场都上音效。

要：

- 开场低频进入。
- 案例段持续铺底。
- 金句前降一点。
- 结论句后留白。

建议音乐段落：

```text
0:00-1:30   轻悬疑，像打开资料夹
1:30-8:00   稳定低频，建立结构
8:00-17:00  稍微加一点节奏，案例展开
17:00-26:30 深一点，讲收费链和风险
26:30-30:00 音乐收束，留工具感
```

## 停顿设计

停顿必须落在关键句后面。不要全程匀速念。

固定停顿：

| 句子 | 停顿 |
|---|---:|
| 这些东西最可怕的地方，不是它们一眼假。 | 0.5s |
| 如果最后我没赚到钱，它已经从我身上赚了什么？ | 1.0s |
| 免费不是福利，是筛选器。 | 0.8s |
| 成功案例不是概率。 | 0.8s |
| 第一笔钱常常不是成交，而是入场券。 | 0.8s |
| 你失败了，他也赚。 | 1.2s |

## 章节转场

每章转场都要像翻案卷：

```text
CASE 01 / 筛选器
CASE 02 / 结果承诺
CASE 03 / 成功案例
CASE 04 / 第二层收费
CASE 05 / 风险转移
CASE 06 / 五个问题
```

转场方式：

- 黑底编号卡。
- 白闪 2-3 帧。
- 轻 tick。
- 卡片从桌面滑入。

## 信息图模板

### 买方 / 卖方对照

```text
买方看到：成功案例、低价、名额、扶持
卖方知道：成本、转化率、失败率、退款门槛
```

### 现金流路径

```text
免费 / 低价入口
→ 正价产品
→ 高阶服务
→ 工具设备
→ 供应链复购
→ 退出成本
```

### 风险转移图

```text
卖方拿走：学费、加盟费、设备费、原料差价、软件费
买方留下：贷款、库存、房租、平台规则、时间成本
```

### 五问工具

```text
1. 中位数结果是多少？
2. 失败者占多少？
3. 后面还要付什么钱？
4. 承诺能写进合同吗？
5. 我失败时它已经赚了什么？
```

## 制作自检

- [ ] 开头 30 秒有没有至少 8 个画面变化？
- [ ] 开场 90 秒有没有把 4 个场景合并到同一张结构图？
- [ ] 每个案例有没有统一资料卡？
- [ ] 每个结论有没有停顿？
- [ ] 有没有至少 6 张可截图保存的卡？
- [ ] 有没有避免“AI 总结口吻”？
- [ ] 有没有真实案例锚点，而不是只讲抽象判断？
