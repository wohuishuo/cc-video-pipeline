# 信息差生意：30 分钟长视频 Brief

## 一句话结论

很多信息差生意最危险的地方，不是它贵，也不是它一定违法，而是它的结构保证了：你成功，它赚钱；你失败，它也已经赚钱。

结尾只保留一句主判断：

> 不要先问这个项目能不能赚钱，先问：如果我失败了，它已经从我身上赚了什么？

## 视频定位

这不是“防诈宣传片”，也不是“骂卖课和加盟”的宣泄视频。

它要做成一条商业结构揭秘片：重点不是警察已经抓了的非法诈骗，而是那些披着合法外衣、合同上可能站得住、但信息极不对称的生意。

官方案例只做可信锚点；主菜是“合法但不道德”的结构：课程、加盟、直播间、陪跑、社群、供应链绑定、不过退费、私域销售。这些场景出现在线上广告、招聘软件、加盟展、微信群和直播间里，很多时候没到立案程度，但合同、账单和后续费用足够让买方亏钱。

用真实案例、简单模型和高密度卡片，把“入口、话术、收费链、风险转移、退出条件”逐层展示出来。

成片验收标准：

- 开场 30 秒出现 4 个具体场景：9.9 课、免费鸡蛋、加盟展、招聘转培训。
- 90 秒内出现主问题卡：`如果我失败了，它已经赚了什么？`
- 每个主案例都展示同一组信息：入口话术、买方看到、卖方知道、后续收费、风险留给谁。
- 结尾给出 5 个可截图问题。
- 全片不出现连续 40 秒纯口播。

## 熟悉入口 + 结构展开

开场不能只依赖“这些场景很常见”。熟悉场景只是入口，后面必须把同一套结构展开到多个行业：

```text
9.9 课
→ 免费鸡蛋
→ 加盟展
→ 招聘转培训
→ 同一张结构图：入口、结果承诺、案例、收费、绑定、退出
```

所以每个案例都要分两层：

- 第一层：具体场景。比如 9.9 课、免费鸡蛋、加盟展、包就业。
- 第二层：结构图。比如筛选获客、分层收费、风险转移、合同退出机制、供应链锁定。

口播上要避免只说“这种骗局很多”。要说：

```text
它们属于不同的行业，
但把商品名字拿掉，现金流路径几乎一样。
```

这句话后面必须接一张现金流路径图，而不是只靠口播。

## 适用人群

- 刷到过副业课、AI 课、剪辑课、配音课的人。
- 想加盟奶茶、小吃、外卖店的人。
- 家里老人接触过免费鸡蛋、健康讲座、私域直播的人。
- 接触过“包就业、保过、不过退”页面、销售电话或协议的人。
- 对商业模式感兴趣，但不想看学术解释的人。

## 核心误区

不要把片子拍成：

```text
信息差骗局有十种销售触发器。
消费者应该提高警惕。
我们要理性消费。
```

要拍成：

```text
你以为它在送鸡蛋，其实它在记录谁到店、谁登记、谁加群。
你以为它在卖课程，其实它在卖“结果承诺 + 升级路径”。
你以为它在承诺不过退费，其实退款条件已经写在小字里。
```

## 小Lin式参考

本片优先参考 `reference/小Lin-日本财团/analysis.md`，不是书单视频。

可复用结构：

```text
熟悉现象
→ 背后统一结构
→ 大白话比喻
→ 真实案例
→ 回到现实判断
```

本片对应：

```text
9.9 AI 课 / 免费鸡蛋 / 奶茶加盟 / 招聘转培训
→ 都是“先筛选动作、再卖结果承诺、再分层收费、最后转嫁风险”
→ 像一台把点击、留资、付款、续费变成现金流的机器
→ 官方案例和常见合同陷阱
→ 五个问题判断项目
```

## 风格

视觉：深底资料卡、合同小字放大、现金流箭头、买方/卖方对照表。

音乐：低音量、持续、轻悬疑，不搞笑，不煽情。

剪辑：开场快，案例段稳，结论句停顿。

卡片：统一深底、白字、红/金/蓝少量强调，像“案件资料卡”。

语气：并肩，不居高临下。不说“你怎么会上当”，而说“这套结构把入口价格、成功案例、合同条款和后续收费分开放在不同位置”。

## 主模型

```text
入口：免费 / 低价 / 内部名额
结果承诺：赚钱 / 健康 / 上岸 / 变美 / 婚恋 / 翻身
证据：成功案例 / 权威背书 / 现场下单 / 群内反馈
绑定：课程 / 设备 / 原料 / 软件 / API / 贷款 / 社群
退出：退费条件 / 合同小字 / 沉没成本 / 面子成本
```

## 不是违法性，而是不对称性

本片不要围绕“它违不违法”展开，而要围绕“它对不对称”展开：

| 问题 | 普法片问法 | 本片问法 |
|---|---|---|
| 课程 | 它是不是诈骗？ | 它的主要利润来自教学，还是来自筛选和升级销售？ |
| 加盟 | 它有没有违法？ | 总部自己靠门店赚钱，还是靠加盟商采购设备和原料赚钱？ |
| 直播 | 它有没有虚假宣传？ | 主播说的“最低价”和“亲测好用”，买方能不能当场验证？ |
| 不过退 | 它有没有写合同？ | 退款条件是否让大多数人事实上退不了？ |
| 社群 | 它是不是传销？ | 收入主要来自产品价值，还是来自发展更多付费成员？ |

本片的价值在这里：

```text
很多亏钱项目，不一定需要一句假话。
它只需要把真实信息分层展示：
销售页展示成功、合同展示免责、社群展示氛围、后台保留失败数据。
```

## 主案例

6 个主案例撑起全片：

1. AI / 剪辑 / 配音副业课：入口低、红利强、后续工具和陪跑收费。
2. 招聘转培训 / 培训贷：从招聘入口进入，最后出现培训账单或分期合同。
3. 餐饮加盟 / 快招公司：低加盟费，利润藏在设备、装修、原料和推广。
4. 老年保健品 / 免费鸡蛋 / 私域直播：免费礼物筛选到店和留资，群直播与专人跟进促复购。
5. 保过 / 不过退 / 包就业：用“零风险”消除防线，用小字重建风险。
6. 平台型供应链副业：教你做生意，实际把你装进它的货源、软件、物流和订单系统。

## 结尾展示的五个问题

1. 不算最好案例，中位数结果是多少？
2. 失败者占多少，主要怎么失败？
3. 除了现在这笔钱，后面必须付哪些钱？
4. 收益、官方合作、成功案例，能不能写进合同？
5. 如果我完全没赚到钱，它已经从我身上赚了哪些钱？

## 标题方向

主推：

```text
你失败了，他为什么还能赚钱？
```

备选：

```text
免费课、低价加盟和保过班的共同结构
信息差生意：最赚钱的不是产品，是筛选你
小人怎么在合法边缘赚大钱？
判断一个项目靠不靠谱，只问这 5 个问题
```

## 封面方向

主推短句：

```text
你失败，他也赚
```

备选：

```text

成功案例不是概率
先问他赚什么
合法边缘的生意
```
