# 小Lin式重做约束 v0.1

问题判断：上一版 Remotion 骨架失败，不是文案问题，是画面语言错了。它是“纯黑底资料卡”，缺少真人机位、实物素材、拼贴背景、关系图、局部放大、字幕和高频切换，所以显得廉价。

参考对象：`reference/小Lin-日本财团/analysis.md` 与抽帧。

## 必须复刻的结构，不复刻品牌

不复刻小Lin本人、Logo、原视频素材；复刻的是画面组织方法：

```text
真人机位 / 素材拼贴 / 关系图 / 字幕 / 小圆窗 / 频繁切镜
```

## 参考片可见规律

### 1. 不是全屏 PPT，是“主持人 + 证据层”

画面常见三种状态：

- 真人中景：主持人正中，背景是书柜/居家工作区，下方一行字幕。
- 全屏素材：历史图、街景、品牌、人物照片铺满画面，主持人小圆窗放左下。
- 信息图：家谱、网络、地图、关系线、关键词卡嵌在画面里，不是孤立黑卡。

### 2. 每 2 秒左右必须有视觉变化

参考片平均镜头 2.24 秒。30 分钟长片不能全程这么密，但关键段必须做到：

```text
开场 0-60s：1.5-2.5 秒一变化
案例段：2-4 秒一变化
结构图段：3-5 秒一变化
结论句：允许停 0.8-1.2 秒
```

### 3. 背景必须有“现实纹理”

不能只用纯色背景。必须用这些之一：

- 重构网页截图。
- 重构合同/表格。
- 泛化 B-roll。
- 账单/发票/收银/手机界面。
- 城市、展会、讲座、办公室、书柜等真实空间。

### 4. 信息图要像“把材料摆出来”

卡片不能是孤立按钮。它应该像：

- 桌面资料。
- 案卷照片。
- 浮动网页。
- 放大镜下的合同。
- 家谱/网络关系图。
- 现金流箭头压在素材上。

### 5. 字幕必须存在

小Lin式画面里字幕不是装饰，是节奏锚点：

- 下三分之一居中。
- 白字，轻阴影。
- 一行优先，最多两行。
- 不遮挡主要证据。

## 本片重做规则

### 开场

旧版：黑底 + 四个按钮。

新版：

```text
四个重构手机/网页界面快速叠上桌面
每个 2 秒
左下角出现主持人小圆窗
主问题用现金流箭头压在四个场景上
```

### 免费鸡蛋段

旧版：六个流程按钮。

新版：

```text
鸡蛋照片/登记表/微信群二维码/讲座投影/检测仪红字/产品套餐
六张素材卡沿时间线推进
每推进一步，底部字幕只说当前动作
```

### 成功案例段

旧版：几个问题卡。

新版：

```text
先铺满收益截图/排队视频/上岸名单
然后把截图缩小到角落
四个数据框压上去：总人数/达标人数/中位数/净结果
```

### 收费链段

旧版：线性文字链。

新版：

```text
用三条轨道：
AI 课 / 加盟 / 供应链
每条轨道是收款节点
节点下面标“谁收钱”
```

### 直播间交付段

旧版：表格。

新版：

```text
直播间画面、下单页面、到手实物三列并排
每列只放可见材料
红线标出无法逐项对应的位置
售后解释作为第四张卡浮出
```

## Remotion 重做方向

当前不需要最终素材，但骨架必须像最终片：

- 增加 `PresenterStage`：模拟主持人机位位置，后续替换真人视频。
- 增加 `EvidenceCollage`：每个场景至少 2-5 张素材卡。
- 增加 `LowerCaption`：每场景底部字幕。
- 增加 `FloatingEvidenceCard`：不是按钮，是截图/合同/账单样式。
- 增加 `NetworkLines`：现金流、关系、流程用线连接。

验收：

- 任何静帧不能只有纯黑背景和几张按钮。
- 每张静帧至少有：背景纹理 + 主标题/字幕 + 2 个以上视觉对象。
- 横屏优先像纪录片资料拼贴，竖屏再重排。
