# 信息差生意素材与镜头清单 v0.1

来源：`script.md`、`storyboard.md`、`visual-cards.md`。

目标：把 30 分钟长片需要的画面素材拆成可执行清单。优先使用可控重构画面和资料卡，不点名未核验商家。

## 素材优先级

| 优先级 | 类型 | 用途 | 处理方式 |
|---|---|---|---|
| P0 | 重构页面 | 承载具体话术、价格、合同条款 | 自制 UI，不出现真实商家名 |
| P0 | 资料卡/表格 | 解释结构、费用、风险 | 按 `visual-cards.md` 制作 |
| P1 | 泛化 B-roll | 提供场景真实度 | 拍摄或用可商用素材 |
| P1 | 官方案例资料卡 | 提供可信锚点 | 截图后只展示标题、机构、日期、摘要 |
| P2 | 抽象转场 | 案卷、现金流、合同放大 | 模板化动效 |

## P0 重构页面

### R01：9.9 AI 副业课销售页

出现时间：0:00-0:22、2:50-4:10、8:55-9:45、18:10-19:10、28:45-29:25

页面元素：

```text
标题：AI 剪辑接单体验课
价格：9.9
话术：零基础 / 每天一小时 / 学完接单
按钮：立即预约直播
角标：限时体验
```

必须隐藏或避免：

- 不出现真实机构名。
- 不出现真实学员头像。
- 收益截图使用重构数字。

用途：

- 作为免费/低价入口。
- 翻面显示工具费、素材版权、平台抽成、客户来源、交付标准。

## P0 资料卡与表格

### C01：四层边界卡

用途：先划边界，避免把高毛利一概写成诈骗。

文案：

```text
正常生意
信息不对称
违法营销
刑事诈骗
```

制作要求：

- 第二层高亮。
- 不使用人物表情或情绪背景。

### C02：行为漏斗卡

文案：

```text
点击 → 停留 → 留资 → 加群 → 付款 → 听完
```

用途：

- 替代抽象描述。
- 对应 2:50-4:10。

### C03：成功案例四数字卡

文案：

```text
总人数？
达标人数？
中位数？
净结果？
```

用途：

- 每次出现收益截图、排队视频、上岸名单时都可复用。

### C04：完整费用链卡

文案：

```text
免费体验 → 基础课 → 高阶课 → 陪跑营 → 会员
→ 工具 → API → 素材 → 设备 → 指定原料
→ 广告代投 → 订单抽成 → 续费维护
```

用途：

- 第四层主卡。
- 可拆三屏用于竖屏。

### C05：风险转移两列表

文案：

```text
卖方拿走：
学费 / 加盟费 / 设备费 / 原料差价 / 软件费 / 广告管理费 / 订单佣金

买方留下：
贷款 / 库存 / 房租 / 平台规则 / 时间成本 / 退款流程 / 账号风险
```

用途：

- 第五层主卡。

### C06：五问清单卡

文案：

```text
1. 中位数结果是多少？
2. 失败者占多少？
3. 后面还要付什么钱？
4. 承诺能写进合同吗？
5. 我失败时它已经赚了什么？
```

用途：

- 结尾截图卡。
- 横屏和竖屏都要单独排版。

## P1 泛化 B-roll

### B01：手机刷短视频/直播间

镜头：

- 手持手机滑动。
- 直播间页面反光，不显示真实商家。
- 手指点击预约/加群按钮。

可替代：

- 全部用重构 UI + 手部素材合成。

### B02：加盟展/签约桌

镜头：

- 展位灯箱。
- 桌面合同。
- 握笔签字特写。
- 奶茶设备、吧台、原料箱。

可替代：

- 泛化餐饮设备 B-roll + 重构招商页。

### B03：健康讲座/登记表

镜头：

- 活动中心桌椅。
- 登记表特写。
- 讲座投影屏。
- 检测仪数字特写。

可替代：

- 重构登记表 + 检测仪 UI 动画。

### B04：招聘与分期

镜头：

- 招聘 App 页面重构。
- 聊天气泡。
- 分期账单页面。
- 合同签署特写。

可替代：

- 纯 UI 动画，不需要真人。

### B05：账单/合同/表格桌面

镜头：

- 桌面摊开合同。
- 放大镜/红框定位小字。
- 计算器或账单表格。

可替代：

- 资料卡动画。

## P1 官方案例资料卡

### O01：招聘转培训典型案例

```text
最高人民法院典型案例
关键词：以招聘为幌子 / 付费培训 / 在线课程 / 入职培训
```

- 不长篇引用正文。

```text
市场监管总局典型案例

```

画面要求：

- 做成蓝色资料卡。
- 用作“链条在现实中出现过”的锚点。

### O03：直播招商典型案例

来源用途：

```text
市场监管总局直播电商典型案例
关键词：招商项目 / 政府帮扶 / 五免政策 / 预期收益
```

- 只做锚点，不把本片全部变成普法讲解。

## 需要设计的可复用组件

| 组件 | 用途 | 复用次数 |
|---|---|---:|
| `CaseCard` | 案例登场 | 6 |
| `TwoColumnCompare` | 买方/卖方、销售页/合同、卖方拿走/买方留下 | 8+ |
| `FlowChain` | 鸡蛋链路、费用链、招聘转培训链路 | 6+ |
| `ContractZoom` | 不过退、政府扶持、包就业条款 | 4+ |
| `NumberBreakdown` | 月入三万、营业额、净利润 | 3+ |
| `FiveQuestions` | 结尾五问 | 2 |

## 拍摄与制作顺序

1. 先做 P0 重构页面和资料卡，能支撑整片主线。
2. 再补 P1 B-roll，避免没有素材时卡住剪辑。
3. 官方案例资料卡只做 3 张，不让视频变成资料朗读。
4. 横屏先完成，竖屏用同一组件改排版。

## 风险控制

- 不出现真实未核验商家名称、Logo、头像、二维码。
- 收益截图必须是重构图，并标注 `示意重构` 或用明显虚构格式。
- 合同页用重构条款，不使用未经授权的真实合同全文。
- 官方案例资料卡只做摘要，不大段复制网页。
