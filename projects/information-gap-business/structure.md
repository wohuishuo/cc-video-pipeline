# 30 分钟成片结构

估算：中文口播 230-260 字/分钟，全片约 7000-7800 字。结构上按 7 个章节，每章 3-5 分钟。

主素材必须来自 `source-material-map.md`。这期不是重新编一套防诈课，而是把用户两份全面文档视频化：

- 附件 A 负责总结构：边界、五个共同结构、五问。
- 附件 B 负责行业密度：话术、行为入口、隐形利益链。

## 总节奏

```text
0:00-1:30   开场：熟悉场景快切 + 主问题
1:30-4:00   边界：不是所有高毛利都是骗
4:00-8:00   第一层：免费和低价是筛选器
8:00-12:30  第二层：卖的不是产品，是结果承诺
12:30-17:00 第三层：成功案例不是概率
17:00-22:00 第四层：利润藏在第二层第三层
22:00-26:30 第五层：风险被转移给买方
26:30-30:00 五问工具 + 总结
```

## 开场视听

开场 0-30 秒参考 `reference/小Lin-日本财团/analysis.md` 的“熟悉例子快切”。

```text
罗森/无印/丰田 → 原来都是财团
```

改成：

```text
AI 课 / 免费鸡蛋 / 奶茶加盟 / 招聘转培训 → 原来都是同一种风险转移结构
```

节奏：

- 0-30 秒：1.5-2.5 秒一切。
- 30-60 秒：切到卡片，留 0.5-0.8 秒停顿。
- 60-90 秒：预告 5 把刀，五张卡片翻开。

## 每章固定模板

每章都按同一套小Lin式结构：

```text
熟悉场景
→ 关键结构不是 X，而是 Y
→ 具体案例
→ 抽象成一句判断
→ 进入下一章
```

## 视觉卡片清单

至少制作这些卡片：

1. 主问题卡：如果我失败了，它已经赚了什么？
2. 四层边界卡：正常 / 割韭菜 / 违法营销 / 诈骗。
3. 漏斗卡：免费内容 → 低价课 → 正价课 → 高阶陪跑 → 工具设备。
4. 买方/卖方对照卡：买方看到什么 / 卖方知道什么。
5. 案例卡 01：老年保健品。
6. 案例卡 02：AI 副业课。
7. 案例卡 03：餐饮加盟。
8. 案例卡 04：招聘转培训。
9. 交付对照卡：直播间拍到 / 页面写到 / 实际收到 / 售后解释。
10. 风险转移卡：利润在卖方，风险在买方。
11. 五问清单卡。

## 音乐和停顿

音乐：

- 开场用低频轻悬疑，配合资料卡、页面截图和合同局部放大。
- 案例段保持低音量，不盖口播。
- 每章结论句前可轻微降音乐，给停顿。

停顿：

- 关键句前 0.4 秒。
- 关键句后 0.8-1.2 秒。
- 案例切模型时停 0.5 秒。

必须停顿的句子：

```text
免费不是福利，是筛选器。
成功案例不是概率。
第一笔钱常常不是成交，而是入场券。
如果你失败了，他仍然赚完了钱，这个项目就要格外小心。
```

## 素材需求预览

素材不需要全部是真实商家画面，可以用“抽象真实感”：

- 手机刷短视频/直播间画面。
- 微信群、合同、价格标签、付款按钮的重构画面。
- 加盟展、奶茶设备、餐车、厨房、门店招牌的泛化 B-roll。
- 老人活动中心、健康讲座、免费礼物的泛化 B-roll。
- 招聘软件、高薪兼职、分期贷款合同的重构画面。
- 官方案例网页截图或资料卡。

## 风险控制

- 不点名具体未核验商家。
- 官方案例用“监管部门/法院公布案例中出现过类似链条”。
- 对灰色模式用“常见、可能、部分案例中”，不做过度断言。
- 明确说：卖课、加盟、高毛利本身不等于诈骗。
