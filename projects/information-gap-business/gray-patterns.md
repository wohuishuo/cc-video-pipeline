# 合法边缘灰色玩法地图

本片的价值不在于复述“已经违法的诈骗”，而是拆那些更常见、更难报警、更像正常商业的玩法。

核心判断：

> 它不一定骗你，它只是把最关键的信息放在你付款之后才让你知道。

## 灰色模式总公式

```text
合法外壳
→ 不完整信息
→ 结果承诺驱动成交
→ 合同保护卖方
→ 风险留给买方
```

最该拍的是这种：

```text
警察看了未必能立案，
但按这套清单检查以后，可以提前看到后续收费和退出成本。
```

## Pattern 01：课程不是产品，课程是筛选器

### 合法外壳

卖课当然合法。知识付费、技能培训、社群陪跑都可以是真生意。

### 脏的地方

低价课的主要目的，不是交付知识，而是筛选已经完成点击、停留、留资和小额付款动作的人：

```text
免费内容
→ 9.9 体验课
→ 正价课
→ 高阶陪跑
→ 私董会 / 工具 / 代理
```

### 屏幕卡片说法

```text
9.9 不是价格，是入口。
它记录谁点击、谁停留、谁进群、谁付款、谁听完转化课。
```

### 视频卡片

```text
表面：卖技能
实际：筛选高意愿客户
风险：学不会、赚不到，钱已付
```

## Pattern 02：成功案例不是证据，是广告素材

### 合法外壳

展示学员案例、加盟商案例、用户评价，本身可以合法。

### 脏的地方

它展示的是“能激发你购买的样本”，不是整体概率。

被隐藏的信息：

- 总共多少人参加？
- 中位数收入是多少？
- 净利润还是营业额？
- 成功者本来有什么资源？
- 失败者有多少？

### 屏幕卡片说法

```text
截图不是财报。
营业额不是利润。
最好案例不是概率。
```

### 视频卡片

```text
买方看到：月入 3 万
卖方知道：1000 人里出了 3 个
```

## Pattern 03：低价入口不是优惠，是收费链的门

### 合法外壳

低价引流、首单优惠、免费咨询，都可以是正常营销。

### 脏的地方

它把注意力集中在第一笔钱上，隐藏后续完整费用链。

```text
加盟费很低
→ 设备很贵
→ 装修指定
→ 原料指定
→ 系统指定
→ 推广指定
→ 后续复购
```

### 屏幕卡片说法

```text
别问加盟费多少。
问开店以后，有多少东西只能从它那里买。
```

### 视频卡片

```text
表面：低价加盟
实际：设备 / 原料 / 装修 / 推广
风险：店亏了，供应链已经赚了
```

## Pattern 04：直播展示不是交付清单，是三处材料对不齐

### 合法外壳

退款协议、服务合同、效果承诺，都可以存在。

### 脏的地方

直播间、下单页、到手品分别展示不同材料：

- 全勤。
- 作业完成率。
- 打卡次数。
- 模考次数。
- 投递数量。
- 退款周期。
- 服务费不退。

### 屏幕卡片说法

```text
看到直播间展示，别只看镜头里的样品。
先看它要求你做到什么，才承认你有资格退款。
```

### 视频卡片

```text
直播间：样品特写
页面：套餐图和规格表
到手：批次、赠品、数量发生变化
```

## Pattern 05：总部扶持不是支持，是控制接口

### 合法外壳

统一品牌、统一系统、统一供应链，在销售材料里会被写成标准化。

### 脏的地方

“统一”可能意味着你不能自己选择：

- 设备。
- 原料。
- 装修。
- 收银系统。
- 推广代运营。
- 物流。
- 账号。

### 屏幕卡片说法

```text
他说“你什么都不用管”。
你要问：那我还控制什么？又承担什么？
```

### 视频卡片

```text
总部负责：系统、货源、推广
你负责：亏损、库存、贷款、房租
```

## Pattern 06：社群不是陪伴，是持续销售环境

### 合法外壳

客户群、学习群、会员群、老年健康群，都可以是服务的一部分。

### 脏的地方

群内环境会持续展示购买和复购信号：

- 成功反馈。
- 老师点评。
- 限时名额。
- 学员晒单。
- 新品预告。
- 不利评论被移除。

### 屏幕卡片说法

```text
页面写的是学习群。
实际运行方式更像一个持续销售场。
```

### 视频卡片

```text
表面：陪伴
实际：复购场
风险：群里反复出现限时名额、晒单、点评和复购提醒
```

## Pattern 07：技术服务变脏，不在收费，在隐瞒来源

### 合法外壳

帮人装软件、部署开源项目、配置 AI 工具、搭本地模型，当然可以收费。

### 脏的地方

它把免费开源包装成“自主研发”，把一次性部署包装成年费授权。

常见问题：

- 不说明软件来源。
- 不说明开源协议。
- 不说明 API 成本。
- 不说明隐私和封号风险。
- 停止续费后远程停用。

### 屏幕卡片说法

```text
收费没问题。
问题是他卖的是服务，还是把别人的免费软件说成自己的资产。
```

### 视频卡片

```text
合理：安装服务费
危险：假装自主研发 + 年费授权
```

## Pattern 08：直播间不是便宜，是控制决策速度

### 合法外壳

直播卖货、限时优惠、主播推荐，本身是正常商业。

### 脏的地方

直播间压缩你的验证时间：

- 倒计时。
- 库存数字。
- 家人们闭眼冲。
- 现场砍价。
- 专拍链接。
- 场外私信成交。

你来不及查：

- 价格是不是最低。
- 主播有没有佣金。
- 产品是否真亲测。
- 评价是否真实。
- 退款路径是否顺畅。

### 屏幕卡片说法

```text
直播间最大的能力，不是给你最低价。
是让你没时间确认它是不是最低价。
```

### 视频卡片

```text
表面：限时福利
实际：压缩验证时间
风险：冲动付款后再慢慢后悔
```

# 本片最好用的总句

```text
很多灰色生意不是靠骗你一句假话赚钱。
它靠的是：
让你在信息最少、验证时间最短、销售提示最密集的时候，
完成一个对卖方最有利的付款或签约动作。
```
