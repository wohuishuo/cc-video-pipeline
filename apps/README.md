# Applications

Every child directory is an independently runnable MVP. Read its README, run its installer, then use its launcher. Internal implementation paths are not public APIs.

For a reusable local-folder or social-URL boundary, start [Source Intake](source-intake/README.md). To turn a verified transcript manifest into editable Russian, English or Kazakh JSON/SRT artifacts, use [Translation](translation/README.md). To synthesize those translations one segment at a time with resumable Edge voices, use [Voice Rendering](voice-rendering/README.md). For browser-managed composition, start [Video Graph Studio](video-graph-studio/README.md). It coordinates public application boundaries while leaving each application's state and outputs under that application's ownership. For private YouTube Data API uploads with a durable redacted receipt, use [YouTube Publisher](youtube-publisher/README.md). For reusable workspace identity and least-privilege admission policy, use [Workspace Access](workspace-access/README.md). For deterministic per-workspace state, artifact and temporary roots, use [Workspace Storage](workspace-storage/README.md). For encrypted local platform-secret custody and one-child injection, use [Credential Vault](credential-vault/README.md). For browser/mobile/hosted command compatibility, use [Client Contracts](client-contracts/README.md). For durable byte/slot reservation leases, use [Resource Budget](resource-budget/README.md); Studio can optionally consume those public lease facts without owning the limits.
