# Applications

Every child directory is an independently runnable MVP. Read its README, run its installer, then use its launcher. Internal implementation paths are not public APIs.

For a reusable local-folder or social-URL boundary, start [Source Intake](source-intake/README.md). For browser-managed composition, start [Video Graph Studio](video-graph-studio/README.md). It coordinates public application boundaries while leaving each application's state and outputs under that application's ownership.
