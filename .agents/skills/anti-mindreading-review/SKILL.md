# 反读心审稿

目标：把“我觉得观众会怎样”“这个让人很高级”“用户因为焦虑所以买”改成屏幕前可验证的表达：画面、声音、动作、账单、合同、数据、流程。

核心原则：

```text
不要替任何人发明内心。
只写发生了什么、展示了什么、隐藏了什么、收了什么钱、谁承担什么风险。
```

## 审查流程

1. 先确认主素材和证据来源。
   - 用户给了附件、原稿、访谈、案例时，优先使用这些材料。
   - 搜索或外部材料只能补充证据，不能替代用户给的主素材。
   - 未核验商家不点名，灰色模式用“常见、可能、部分案例中”。

2. 扫描读心红旗。
   - 心理猜测：`觉得`、`感觉`、`相信`、`焦虑`、`恐惧`、`贪婪`、`从众`、`信任`、`认同`、`安全感`、`心动`。
   - 精神分类：`这类人`、`底层心理`、`用户画像就是`、`他们想要`、`他们害怕`。
   - 自我感动：`高级感`、`发现新大陆`、`懂了秘密`、`脑洞大开`、`爽点`、`情绪价值`。
   - 观众脑补：`观众会觉得`、`观众会被吸引`、`让人感觉`、`让人忍不住`、`提高留存`。

3. 判断每个红旗词是否有可见证据。
   - 可以保留：作为用户原文、素材分类、销售话术原句、研究对象标签，并明确标注来源。
   - 必须改写：用它解释成交、解释观众反应、解释人物内心、解释视频效果。

4. 用“六类事实”替换。
   - 画面事实：页面写了什么、卡片出现什么、合同小字是什么、截图展示什么。
   - 声音事实：口播说了什么、停顿多久、BGM 何时降下去、音效何时出现。
   - 行为事实：点击、停留、留资、加群、付款、签约、复购、退款、投诉。
   - 钱流事实：学费、加盟费、设备差价、原料、软件、广告代投、抽成、续费。
   - 规则事实：合同条件、退款门槛、平台规则、资质、承诺能否写进合同。
   - 数据事实：总人数、中位数、成功占比、净利润、失败者数量、成本口径。

5. 输出时先给问题，再给改法。
   - 不要只说“这里有点抽象”。
   - 指出原句为什么越界。
   - 给出可以直接替换进稿子的句子。

## 改写规则

优先使用这些替换：

```text
“用户相信了” → “用户完成了留资、加群、付款或签约动作”
“制造焦虑” → “反复展示收入/健康/教育/婚恋问题，并给出付费入口”
“获得信任” → “使用老师、专家、总部、平台、案例、证书作为背书”
“卖未来身份” → “卖结果标签或结果承诺”
“让人心动” → “页面只展示最好案例、最低首付、限时名额或高收益截图”
“观众会觉得高级” → “画面使用深底资料卡、合同放大、现金流箭头、停顿和低频音乐”
“提高防诈意识” → “结尾给出可截图的五个核验问题”
```

## 审稿输出格式

对短稿，直接给三段：

```text
结论：这稿子是否仍在读心。
主要问题：列 3-8 条，引用原句或定位文件行。
替换稿：给可直接使用的改写版本。
```

对长稿或项目文件，按文件输出：

```text
文件：path
红旗句：原句
问题：它在猜测谁的内心，或在用抽象标签代替什么证据
改成：可看到/可听到/可核验版本
```

最后加一条自检：

```text
如果把旁白关掉，只看画面和字幕，这个判断还能成立吗？
如果不能，就继续改。
```

## 视频脚本特别标准

每个核心判断必须能对应至少一种镜头：

- 漏斗图：免费/低价入口 → 留资 → 加群 → 正价课 → 高阶产品。
- 对照卡：买方看到什么 / 卖方知道什么。
- 账单图：第一笔钱 / 后续必须支付 / 退出成本。
- 合同图：大字承诺 / 小字条件。
- 案例图：最好案例 / 总人数 / 中位数 / 净利润。
- 风险图：卖方拿走什么 / 买方留下什么。

不能只写：

```text
这会让观众觉得很高级。
```

要写：

```text
这句后停 0.8 秒，画面切黑底大字卡；下一镜把成功案例截图缩小，旁边补三项空白数据：总人数、中位数、净利润。
```

## 最终验收

完成审查后，运行一次关键词扫描或手动复查：

```text
观众|让人|觉得|感觉|相信|愿意|打动|吸引|留存|心动|高级|懂了|爽|焦虑|恐惧|贪婪|从众|心理|身份|错觉|幻觉|安全感|信任|认同|想象
```

允许剩余命中只出现在：

- 明确引用的原始素材。
- 审查规则本身。
- 被批评的原句。
- 已经转写为可验证事实的说明。

否则继续改。
