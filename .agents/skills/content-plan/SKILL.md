# 选题与标题 (content-plan) — 骨架 / 待迭代

## 流程（由 Codex 执行）
1. 输入：方向/关键词，或一篇 reference/<slug>/analysis.md。
2. 选题：发散 5–8 个角度，按"我能做+有受众+差异化"打分排序。
3. 标题：每个选题 3–5 版，标注钩子类型（提问/反常识/利益/情绪/悬念）。
4. 平台适配：B站偏信息量、抖音/TikTok偏强钩子短句。
5. TikTok 出海：中文标题 + 俄/英/日译版（不是直译，按各语种平台习惯改写）。

## 输出 `projects/<x>/titles.md`
| 选题 | 标题候选 | 钩子类型 | 平台 | 评分 |
