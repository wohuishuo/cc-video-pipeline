# 金字塔写稿 (script-pyramid) — 骨架 / 待迭代

> 这是个人表达训练重点：稿子结构**必须**金字塔——结论先行、分层展开。

## 流程（待补脚本，目前由 Codex 直接执行）
1. 读 `projects/<x>/brief.md` 拿选题与目标平台。
2. 先逼出**一句话结论**（金字塔顶）。不清晰就反问用户。
3. 搭 3 个 MECE 支撑论点（互斥、穷尽）。
4. 每个论点：论据 + 故事/例子 + 一句过渡。
5. 开场 8 秒钩子单独写（参考 ref-analyze 沉淀的 SOP）。
6. 输出 `script.md`，标注预估时长（按 ~240 字/分钟中文口播）。

## 输出结构
```
钩子(0-8s) → 结论 → 论点1(据+例) → 论点2 → 论点3 → 收束(回扣结论) → 互动引导
```
